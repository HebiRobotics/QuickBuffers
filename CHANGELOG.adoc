= QuickBuffers

== 1.5

TL;DR: improved JSON support and fixed some minor issues that were found by an agent review.

Added features

* added `JsonReader` and `JsonWriter` for reading and writing JSON without messages (experimental)
* added `ByteBuffer` setters to `RepeatedBytes` (#72), `RepeatedMessage::sort`, `RepeatedString::getUtf8String` and `reserveGrowing` for repeated fields
* added support for integral values such as `1.0` or `1e3` in JSON integer fields, enum alias names, and a leading UTF-8 byte order mark

Behavior changes

* raised the minimum Java version of the runtime to 8. The 1.5 runtime still supports messages generated by 1.4, but messages generated by 1.5 need the new runtime.
* aligned the built-in `JsonSource` more closely with Protobuf-Java: stricter input parsing that rejects forms such as `+1` or `.5`, and a 64-level recursion limit
* changed `uint64` and `fixed64` values above 2^63 to be written to JSON as unsigned instead of negative numbers
* changed repeated scalar fields in proto3 files to be packed by default. Proto2 files are unchanged
* changed the built-in `JsonSource` to read input streams through a buffer, so it may read past the end of the root value
* the `linux-aarch_64` plugin now needs glibc 2.35 or newer (Ubuntu 22.04+)
* updated the bundled protoc and the generator's protobuf-java to 4.36.2

Performance

* reading JSON with the built-in `JsonSource` no longer allocates in steady state, and numbers and base64 are converted without intermediate strings or arrays
* repeated strings are written without decoding them first

Fixes

* improved error messages in JSON parsing
* fixed a number of edge case bugs found in an agent review
** repeated fields: `addAll` and `copyFrom` ignoring the array offset, reused elements keeping old values, adding a repeated enum to itself
** malformed binary input: negative or very large lengths, integer overflows, `ByteBuffer` sources reading past nested fields
** JSON: hangs on truncated input, truncated `int32` and enum values, `uint64` values above 2^63, base64 without padding, escaped forward slashes
** `ByteBuffer` calls failing on Java 8, tagged native addresses on Android, closing a `JsonSink` clearing the output buffer

== 1.0.0

* released GraalVM native images of the generator plugin for simpler maven integration
* added native-image config files for the runtime. The other parts (generated messages) don't need any configuration, so everything works out of the box.
* changed JsonSource behavior for null inputs to match ProtobufJava's `JsonFormat` (fixes #29)

== 1.0-rc1

* added support for `ByteBuffer`, `InputStream`, `OutputStream`
* changed API to be closer to Protobuf-Java. Non-backwards compatible, but mostly function renaming
* improved JSON support and added basic reading capabilities
* added quickbuf-compat for interfacing with Jackson and Gson
* changed license from GPL to Apache v2
